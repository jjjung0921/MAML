# Notes — 튜터가 쓴 개념 설명

DR-0011로 도입했다. Phase 02 개념을 원문으로 읽기 전에 배경을 잡는 용도다.

## 이 폴더의 지위

- **이해 상태의 근거가 아니다.** Truth 순서에서 ⑨(튜터의 인상)와 같은 급이다. `concepts/`의 `state`는 `exercises/`의 채점 기록으로만 바뀐다(Rule 8).
- **학습자의 Definition·Claims를 대신하지 않는다.** `concepts/`의 그 칸은 학습자가 자기 언어로 쓴다. 노트 문장을 옮겨 적은 것은 학습자 언어가 아니다.
- 노트를 읽은 것은 원문을 읽은 것이 아니다. `evidence/`의 `status`는 그대로 학습자의 원문 읽기 상태다.

## 읽는 순서

1. 노트를 읽는다 (배경).
2. 노트가 가리키는 `evidence/finn2017-maml.md` 앵커에서 **원문 문장**을 확인한다.
3. `concepts/<slug>.md`에 **자기 언어로** Definition과 Claims를 쓴다. 노트를 보지 않고 쓴다.
4. exercise로 판정한다.

3번을 노트를 열어 놓고 하면 이 폴더는 학습을 방해한다.

## 규칙

- 사실 주장에는 근거 라벨(`[fact]`·`[derived]`·`[assumption]`·`[hypothesis]`·`[unsupported]`)과 `evidence/` 포인터를 붙인다(Rule 7).
- 핵심 유도는 끝까지 풀지 않는다. 방향과 도구까지만 준다.
- 출제된 exercise의 정답을 담지 않는다.
