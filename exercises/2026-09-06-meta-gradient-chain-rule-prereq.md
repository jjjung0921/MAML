# meta-gradient 선수 배경 진단 — 합성함수 연쇄법칙

## Problem

MAML 용어를 쓰지 않는 순수 미적분 문항이다. 자료를 찾지 않고 푼다. ASCII 수식·손글씨 사진·말로 푼 설명 모두 가능하다.

f 는 실수 하나를 받는 미분 가능한 함수이고, a 는 고정된 상수다. 다음을 정의한다.

    u(x) = x - a * f'(x)
    g(x) = f( u(x) )

1. dg/dx 를 f 와 그 도함수들로 나타내라. 어떤 규칙을 어디에 적용했는지 한 줄로 밝힌다.
2. f(x) = x^2, a = 0.1 일 때 x = 1 에서 dg/dx 의 값을 구하라.
3. 2번에서 f''(x) 가 들어간 항을 0으로 두고(즉 그 항을 무시하고) 같은 값을 다시 구하면 얼마인가? 두 값의 차이는 어디에서 왔는가?

## Rubric

<details>
<summary>답변 후에 연다</summary>

- R1. (필수, meta-gradient C2) g 를 f 와 u 의 합성으로 보고 dg/dx = f'(u(x)) * u'(x) 로 분해한다. 연쇄법칙을 적용했다고 밝힌다. f'(x) 만 쓰고 안쪽 미분을 빠뜨리면 미충족.
- R2. (필수, meta-gradient C1·C3) u'(x) = 1 - a * f''(x) 를 얻어 dg/dx = f'(x - a*f'(x)) * (1 - a*f''(x)) 로 쓴다. a 를 상수로(x 에 의존하지 않는 값으로) 취급했음이 드러나야 한다.
- R3. (필수, 계산) f'(x) = 2x, f''(x) = 2, u(1) = 0.8, f'(0.8) = 1.6, (1 - 0.1*2) = 0.8 이므로 dg/dx = 1.28. 최종 수치가 1.28 이어야 한다.
- R4. (필수, 계산·해석) f'' 항을 무시하면 1.6 이며 차이 0.32 는 u'(x) 안의 -a*f''(x) 항에서만 온다고 짚는다. 단순히 "값이 다르다"만으로는 미충족.
- 판정: 필수 4항목 전부 충족 시 pass, 일부만 충족하면 partial, R1 을 못 하면 fail. 항목마다 Attempt 인용. 표기가 아니라 수학을 채점한다(프라임 대신 말로 "미분"이라 써도 무방).
- 이 문항은 순수 미적분 선수 배경 확인이며 MAML 개념 이해를 판정하지 않는다.

## Attempt

학습자 응답(2026-09-06, 텍스트 입력, 원문 그대로):

1. f'(u(x))u'(x)가 된다. chain rule이 사용된다.
2. 2u(x)u'(x) = 2 * 0.8x * (1 - 0.1 * f''(x)) = 1.6 * 0.8
3. 1.6 / f''(x)를 0으로 근사해서 온다.

## Grading

grader: claude-code (general-purpose 분리 컨텍스트, Rubric·Attempt만 전달). 2026-09-06.

- R1. ✓ — 인용 "f'(u(x))u'(x)가 된다. chain rule이 사용된다." — 합성으로 보고 바깥 도함수와 안쪽 도함수의 곱으로 분해했고 연쇄법칙 사용을 밝혔다.
- R2. ✓ — 인용 "2 * 0.8x * (1 - 0.1 * f''(x))" — u'(x)를 1 - a*f''(x) 꼴로 잡았고 a=0.1이 미분 후에도 계수로 남아 상수 취급이 드러난다. 일반형을 명시하지 않고 a 대입 상태로만 나타난 점은 기록해 둔다.
- R3. ✗ — 인용 "2 * 0.8x * (1 - 0.1 * f''(x)) = 1.6 * 0.8" — 인수 1.6과 0.8은 옳으나 곱을 끝내지 않아 최종 수치 1.28이 제시되지 않았고, f''(x)가 마지막 표현까지 미대입으로 남았다. 힌트: 요구된 것은 x=1에서의 값이므로 남은 곱셈 한 번을 수행해 하나의 수로 끝낸다.
- R4. ✗ — 인용 "1.6 / f''(x)를 0으로 근사해서 온다." — 무시했을 때의 값 1.6과 원인 지목은 맞으나 차이 0.32를 수치로 내지 않았고, 그 차이가 u'(x) 안의 -a*f''(x) 항에서만 온다는 지목이 없다. 힌트: 두 계산에서 달라진 인수가 정확히 어느 하나인지 지목하고 그 차이가 곱 전체에 얼마의 차를 만드는지 수로 적는다.
