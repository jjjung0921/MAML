# DR-0006: 이틀 MAML 핵심 학습과 후속 연구 독해

- Status: Accepted
- Date: 2026-09-05
- Deciders: 학습자(목표·이틀·하루 120분), codex(최소 구성·검증 설계)

## Context

학습자는 MAML을 숙지해 계열 연구를 읽고자 하며 사전 지식으로 “FOMAML이 Hessian의 계산 복잡도로 인해 선호되었다는 점”을 말했다. 기존 원문 분석이 있지만 exercise 증거는 없다.

## Problem

이틀 총 240분에 검증 가능한 독해 기반을 구성하면서 숙련도·보편적 독해 능력을 근거 없이 선언하지 않아야 한다.

## Alternatives

1. 전체 구현·벤치마크·변형 논문 여러 편 — 넓은 경험 / 시간 초과 및 학습자 이해 확인 축소.
2. 다섯 개념과 후속 논문 한 편의 발췌 독해 — 검증 가능한 최소 목표 / 재현·심화 이론·분야 전체 지식은 제외.

## Decision

- 2번 선택. G1 과제/목적함수, G2 exact/FOMAML 미분 경로, G3 연구 독해로 구성한다.
- 기존 MAML 분석을 보조 자료로 재사용하고 MAML 원문과 ANIL 발췌 후보를 등록한다. 자료 접근 확인은 U3다.
- subject 폴더 MAML을 유지한다. 연결된 하나의 concept map을 가지며 이번에 이름 변경은 필요하지 않다.
- 다음 U2부터 unit 160분 + 15개 unit의 기록 75분 + 중간 재개 기록 5분 = 240분. unit마다 짧은 세션으로 진행해 새 unit 하나와 마지막 5분 기록 규칙을 지킨다. 초기화 자체의 추정 20분은 튜터 작업이다.
- 템플릿 default_budget 30·복습 및 판정 기본값 유지. 하루 120분은 직접 확인, 세부 기본값은 기존 제안을 유지한 운영 가정으로 LEARNER와 HANDOFF에 공개한다.
- ROADMAP에 REVIEW를 추가한다: 학습·capstone 통과 후 날짜별 검증만 남은 Phase는 REVIEW로 보존하고 다음 Phase를 시작할 수 있다. 동시에 IN_PROGRESS인 Phase는 하나, 공식 DONE은 여전히 verified를 요구한다.
- 이틀 내 핵심 학습·capstone 초회 통과를 목표로 한다. 공식 Phase DONE·verified에 필요한 서로 다른 날 증거가 부족하면 REVIEW로 남기고 후속 평가를 한다. Rule 8을 완화하지 않는다.

## Rationale

미래 모든 연구의 독해를 보장할 수 없으므로 새로운 발췌에서 실제 비교·전이를 평가한다. 구현보다 데이터·변수·의존 관계·근사·근거의 경계를 우선한다. 후속 논문의 새로운 수학은 필요할 때 별도로 학습한다.

## Consequences

- 모든 개념은 unseen이며 Definition·Claims·verified_by는 비어 있다. 초기화는 이해도 증거가 아니다.
- Phase 01과 02만 상세화하고 Phase 03은 독해 묶음·시간만 둔다. U2 결과로 Phase 03 진입 시 상세 PLAN을 작성한다.
- 진단 실패·독해 재시도로 예산을 초과하면 근거와 함께 기간/범위 조정을 제안한다.
- 기존 AGENTS의 사용자 추가 규칙·분석 파일·역할 메모리 안내는 보존한다. 초기화 절차 파일은 요청된 절차대로 삭제한다.
- verified 이후 복습 3·7·21·60일은 이틀 집중 학습 뒤에도 계속 적용한다. 예약 자동화는 생성하지 않는다.
- DR-0001~0005는 기존 방법 결정의 이력이므로 수정하지 않는다. 그 안의 초기화 파일 언급은 과거 반영 위치 기록이며 활성 실행 지시가 아니다. 활성 문서의 초기화 파일 참조는 제거한다.
